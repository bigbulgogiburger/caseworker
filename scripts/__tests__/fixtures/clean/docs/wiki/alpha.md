# 알파 (Alpha)

> 알파 도메인의 현재-상태 종합. 모든 규칙 문장에 출처가 결박돼 있다.

## 현재 규칙

- 알파 저장은 관문 하나만 지나고 값은 저장 시점에 동결된다 (ADR-001).
- 형제 이슈와의 연계는 이벤트 한 방향으로만 흐른다 (ABC-123).

## 경계·계약

- 알파는 베타의 상태를 직접 바꾸지 않는다 — 계약은 이벤트뿐이다 (ADR-002).
